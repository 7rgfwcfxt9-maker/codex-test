# Personal AI Assistant

A small dependency-free Python web app with a local, chat-style personal
assistant. It does not require an API key or an internet connection: responses
are generated by simple built-in rules.

## Features

- Chat-style interface with a scrolling message history.
- Text input and **Send** button for submitting messages.
- Local `POST /chat` JSON endpoint for assistant replies.

## Setup

```bash
pip install -r requirements.txt
```

## Run the app

```bash
python app.py
```

Then open <http://127.0.0.1:5000/>.

Type a message and select **Send**. The conversation remains visible in the
message history for as long as the page is open.

## Test

```bash
python -m unittest
```
